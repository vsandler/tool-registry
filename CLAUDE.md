# Tool Registry: Project Rules

## 1. Made-up data only
Use only fictional, clearly invented data (names, emails, companies, numbers).
Never use or add real personal or customer data.

## 2. Never touch secrets
Do not open, read, print, edit, or commit `.env` / `.env.*` files, API keys, tokens, or passwords.
If a task seems to need a secret, stop and ask me instead.

## 3. Explain every change in plain language
Before or after each change, tell me what changed, why, and what it affects, in simple terms
without unexplained jargon.

## 4. Keep tests passing
Run the tests after every change. If something breaks, fix it before moving on.
Never delete, skip, or weaken a test just to make it pass.

## 5. Nothing from any employer
Never replicate any employer's systems, names, data, code, or internal processes.
Build everything from scratch using generic examples.
